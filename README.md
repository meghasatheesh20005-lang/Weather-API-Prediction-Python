Weather API Prediction Using Python

📌 Project Overview

Weather API Prediction is a Python project that displays real-time weather information for a selected city using the OpenWeather API. It helps users check current weather conditions through a simple and user-friendly web application.

🎯 Objectives

- Display real-time weather information.
- Search for weather details by city name.
- Show temperature, humidity, and wind speed.
- Display weather conditions and icons.
- Learn API integration and web application development using Python.

📊 Data Source

The application retrieves weather information from the OpenWeather API, including:

- City Name
- Country
- Temperature
- Feels-like Temperature
- Humidity
- Wind Speed
- Weather Description
- Weather Icon

🛠️ Technologies Used

- Python
- Flask
- OpenWeather API
- HTML
- CSS
- Bootstrap
- Requests Library

⚙️ Project Workflow

1. User enters a city name.
2. The Flask application receives the request.
3. The application sends a request to the OpenWeather API.
4. The API returns current weather information.
5. Python processes the response.
6. Weather details are displayed on the web page.

🌦️ Key Features

- Search weather by city name.
- Display current temperature and feels-like temperature.
- Show humidity and wind speed.
- Display weather descriptions and icons.
- Provide a simple and responsive user interface.

📈 Results

The application successfully retrieves and displays real-time weather information for valid city names when the API is available and the API key is configured correctly.

💡 Key Benefits

- Provides quick access to weather information.
- Demonstrates real-time API integration.
- Helps users understand current weather conditions.
- Improves practical Python and Flask development skills.

🚀 Future Enhancements

- Add a 5-day weather forecast.
- Display weather information for multiple cities.
- Add interactive weather charts.
- Improve error handling for invalid city names.
- Deploy the application online.
